### 2. Handwritten Character Recognition

A deep learning project that recognizes handwritten characters using a **Convolutional Neural Network (CNN)** trained on the **EMNIST Balanced** dataset.

**Dataset:**

* 112,800 training images
* 18,800 testing images
* 47 character classes
* 28 × 28 grayscale images

**Technologies:**

* Python
* TensorFlow
* Keras
* NumPy
* Matplotlib
* Scikit-learn

**Model:** Convolutional Neural Network (CNN)

**Test Accuracy:** 86.39%

[View Handwritten Character Recognition →](./CodeAlpha_HandwrittenCharacterRecognition)
